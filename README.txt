記事メーカー PWA（初心者向け）

【この版でできること】
- 商品情報を入力してX投稿案／ブログ記事案をテンプレート作成
- 文章コピー
- 下書きを端末内に保存・表示・削除
- 保存した下書きをテキストファイルに書き出し
- PWAのmanifestとservice workerを備え、HTTPSで公開後に対応ブラウザからホーム画面へ追加

【まだできないこと】
- Amazonの商品検索、価格・評価・レビュー件数の自動取得
- AIモデルを使った自由な記事生成
- 毎日指定時刻にバックグラウンドで自動作成
- Xやブログへの自動投稿

【公開手順の概要】
1. GitHubにログインし、新しい公開リポジトリを作成（例：article-maker）。READMEの自動作成はオフにしてもオンにしてもよいですが、アップロード時に同名ファイルの競合に注意してください。
2. このZIPを解凍し、index.html、manifest.webmanifest、sw.js、iconsフォルダの中身をリポジトリの一番上にアップロードします。article-pwaフォルダ自体を1段深く入れないでください。
3. リポジトリの Settings → Pages を開き、Build and deployment の Source を Deploy from a branch、Branch を main、Folder を /(root) にして Save。
4. 数分待ち、Settings → Pages に表示されるサイトURLを開いて確認します。公開URLは通常 https://ユーザー名.github.io/リポジトリ名/ の形式ですが、実際に表示されたURLを使ってください。
5. AndroidのChromeで公開URLを開き、右上の︙メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

【重要】
- GitHub Pagesは公開サイトです。APIキー、パスワード、個人情報をHTMLやリポジトリに書き込まないでください。
- 端末内保存データはブラウザデータを消すと消える可能性があります。大切な下書きはテキスト書き出しをしてください。
- Amazonアソシエイトの個別商品リンクは、公式ツール等で作成し、公開前にリンクと規約を確認してください。
- 定時自動実行やAIによる商品検索を追加するには、バックエンド/API接続とスケジューラ等の追加開発が必要です。秘密鍵をブラウザ側に埋め込まないでください。
